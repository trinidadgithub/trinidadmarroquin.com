Post-Provision VM State Verification With NetBox

After Terraform creates or resizes a vSphere VM, verify NetBox reflects the same lifecycle state. This check is separate from preflight. Preflight prevents unsafe allocation before apply. Post-provision verification proves source-of-truth state matches what Terraform just changed. Set Lookup Values Use generic environment variables so the commands are reusable: export VM_NAME="cluster-a-app-01" export VM_IP="192.0.2.10" export VM_DNS_NAME="cluster-a-app-01.example.com" export NETBOX_CLUSTER_NAME="cluster-a" NetBox API credentials: export NETBOX_SERVER_URL="https://netbox.example.com" export NETBOX_API_TOKEN="..."
